This repository is developed independently:

- **Hardware:** personal Windows 11 workstation, purchased by me, not furnished
  by any employer or customer.
- **Network:** personal network. No employer network or VPN.
- **Accounts:** personal accounts throughout (GitHub organisation
  `secure-builder-dev`, personal email). No employer-provided credentials,
  licenses, subscriptions or infrastructure are used.
- **Time:** outside of any employer's duty hours.
- **Inputs:** the behavioral specification package under `specs/` —
  documents 00–08, 10 and 11 — authored by me. Document 09 (private
  commercial memo) is deliberately not present in this repository. No source
  code from any other repository, including my own earlier harness, is
  copied, imported, adapted, cloned to this machine, or consulted during this
  build.
- **Method:** implementation written from the specified behavior, using an AI
  coding assistant driven by me, from the specifications alone. Where the
  specification names a concrete artifact, that naming is illustrative
  (spec 06, REQ-8.2); implementation choices here are made independently.
  Ambiguities are resolved by amendment to the specification
  (spec 07 §5.3), recorded in `AMENDMENTS.md`, never by reference to any
  prior implementation.
- **Remote:** secure-builder-dev/secure-builder, branch engine, started
  as a history-free branch. Nothing from that remote's other branches was
  fetched onto this machine.

Commits are signed with an SSH key generated on this machine for this
purpose (`engine-signing`, ed25519). See `records/.build-log.md` for the
contemporaneous record.
